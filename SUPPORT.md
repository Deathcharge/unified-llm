# Support

`unified-llm` is maintained by Samsarix LLC.

## Where to ask

- Use the [repository issue tracker](https://github.com/Deathcharge/unified-llm/issues) for reproducible bugs and feature requests that are safe to discuss publicly.
- Email `support@samsarix.com` for installation, configuration, compatibility, or other product-support questions that should not begin in a public issue.
- Email `contact@samsarix.com` for general, partnership, and commercial inquiries.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

## What to include

Include the package version or commit, Python version, operating system, smallest reproducible example, expected behavior, actual behavior, and sanitized error type/message. For provider-compatibility questions, include the endpoint product and documented protocol family, but not its credential or private URL.

Never send API keys, authorization headers, custom secret-bearing headers, prompt or response bodies, customer data, or provider account exports. Replace sensitive values with synthetic placeholders before sharing logs or examples.

## Prerelease support boundary

Version `0.1.0` is an alpha release candidate. Samsarix LLC has not published guaranteed response or remediation times for this prerelease package. Support does not cover third-party provider availability, retention policy, billing, quota decisions, or behavior outside the documented OpenAI-compatible subset.
