# Contributing

## Setup

```bash
python -m venv .venv
```

Activate the virtual environment, then install development tools:

```bash
python -m pip install -e ".[dev]"
```

## Required checks

```bash
python -m ruff check .
python -m ruff format --check .
python -m mypy unified_llm tests examples
python -m pytest --cov=unified_llm --cov-report=term-missing
python -m build
python -m twine check dist/*
```

Tests must not contact live APIs or require credentials. Use a custom fake provider or `httpx.MockTransport`.

## Change discipline

- Preserve the explicit route model; do not infer provider names from model strings.
- Treat retry classification, exception fields, provider protocol parameters, and exported names as public API.
- Add a changelog entry for user-visible changes.
- Never commit credentials, captured prompts/responses, generated bytecode, build output, or local environments.
- Provider adapters must honor cancellation and timeouts, sanitize errors, and document any content sent across a new trust boundary.

## Pull requests

Describe the user problem, behavior change, tests added, compatibility impact, and security/cost implications. The current licensing ambiguity is an owner decision; do not replace or reinterpret license files in an ordinary contribution.
